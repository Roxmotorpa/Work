# Marketing ROX Motor Panamá

Este repositorio guarda el trabajo del equipo de marketing en un solo lugar: guías de marca, campañas, contenido, reportes y plantillas.

Todo cambio queda registrado, con quién lo hizo y cuándo. Así siempre se puede volver a una versión anterior.

## Cómo está organizado

| Carpeta | Qué va aquí |
|---|---|
| `marca/` | Guía de marca: tono de voz, colores, tipografías, uso del logo, mensajes clave |
| `campanas/` | Una subcarpeta por campaña, con su brief, sus piezas y sus resultados |
| `contenido/` | Textos para redes sociales, blog, email y la web, más el calendario editorial |
| `recursos/` | Logos, fotos de vehículos e imágenes aprobadas |
| `reportes/` | Reportes mensuales y de cierre de campaña |
| `plantillas/` | Formatos para copiar y llenar (brief, calendario, reporte) |

## Cómo empezar una campaña nueva

1. Crea una carpeta dentro de `campanas/` con el formato `AAAA-MM-nombre` (ej. `2026-12-lanzamiento-navidad`).
2. Copia ahí `plantillas/brief-campana.md` y llénala.
3. Guarda las piezas y los textos de la campaña en esa misma carpeta.
4. Al terminar, agrega el reporte usando `plantillas/reporte-campana.md`.

## Reglas básicas

- Nombres de archivo en minúsculas, sin tildes ni espacios (usa `-`): `post-instagram-rox01.md`.
- No subir contraseñas, datos personales de clientes ni bases de datos de contactos.
- Los archivos muy pesados (videos largos) van mejor en Google Drive; aquí se deja el enlace.
